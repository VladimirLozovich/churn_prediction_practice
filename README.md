# Прогнозирование оттока клиентов

Учебный проект для ознакомительной практики.
Цель: Сравнить модели Random Forest и Gradient Boosting и интерпретировать результаты с помощью SHAP.

## Как запустить
1. Создайте и активируйте виртуальное окружение: `python -m venv .venv`
2. Установите зависимости: `pip install -r requirements.txt`
3. Запустите Jupyter Notebook и откройте файлы из папки `/notebooks`.
