# Сравнительный анализ ансамблевых методов для прогнозирования оттока клиентов телеком-оператора

## О проекте

**Цель проекта:** Разработать и сравнить несколько ансамблевых моделей машинного обучения для решения задачи бинарной классификации — прогнозирования оттока клиентов. Основной задачей является не только построение точной модели, но и интерпретация ее результатов для выявления ключевых факторов, влияющих на решение клиента покинуть компанию.

## Описание данных

В качестве исходных данных используется публичный датасет **"Telco Customer Churn"** с платформы Kaggle.
[Ссылка на датасет](https://www.kaggle.com/datasets/blastchar/telco-customer-churn)

Датасет содержит информацию о ~7000 клиентах телеком-компании и включает в себя:
- **Демографическую информацию:** пол, возраст (пенсионер), наличие партнера и иждивенцев.
- **Информацию о подключенных услугах:** телефон, интернет (DSL/оптоволокно), онлайн-безопасность, техподдержка, стриминговые сервисы и др.
- **Информацию о контракте и платежах:** тип контракта (помесячный, на год, на 2 года), способ оплаты, ежемесячные и общие платежи.
- **Целевую переменную `Churn`:** ушел ли клиент в последнем месяце.

## Методология

Работа над проектом включала следующие этапы:

1.  **Исследовательский анализ данных (EDA):** Визуализация данных для выявления закономерностей, зависимостей и понимания ключевых факторов, влияющих на отток. Было установлено, что данные являются несбалансированными.
2.  **Предобработка данных:** Очистка, преобразование типов данных, кодирование категориальных признаков (One-Hot Encoding, Label Encoding) и масштабирование числовых признаков (StandardScaler).
3.  **Борьба с дисбалансом классов:** Применение техники **SMOTE (Synthetic Minority Over-sampling Technique)** к обучающей выборке для создания сбалансированного набора данных, что позволяет модели лучше изучить характеристики миноритарного класса (ушедших клиентов).
4.  **Моделирование и подбор гиперпараметров:**
    - Обучение и сравнение четырех типов ансамблевых моделей: **Random Forest** (бэггинг), **XGBoost** и **LightGBM** (бустинг), а также **Stacking** (ансамбль ансамблей).
    - Для каждой модели был произведен подбор оптимальных гиперпараметров с помощью `RandomizedSearchCV` с целью максимизации метрики `f1-score`.
5.  **Оценка моделей:** Сравнение моделей проводилось на основе ключевых метрик классификации: **Precision**, **Recall**, **F1-score** и **ROC-AUC**. Особое внимание уделялось метрике **Recall** для класса "ушедшие клиенты", так как с точки зрения бизнеса важнее всего идентифицировать как можно больше потенциально уходящих клиентов.
6.  **Интерпретация лучшей модели:** Для лучшей модели (Optimized XGBoost) был проведен глубокий анализ с помощью библиотеки **SHAP (SHapley Additive exPlanations)** для выявления вклада каждого признака в итоговое предсказание.

## Установка и запуск

Для запуска проекта на локальной машине выполните следующие шаги:

1.  **Клонируйте репозиторий:**
    ```bash
    git clone <URL вашего репозитория>
    cd <название папки проекта>
    ```

2.  **Создайте и активируйте виртуальное окружение:**
    ```bash
    # Для Windows
    python -m venv .venv
    .venv\Scripts\activate

    # Для macOS/Linux
    python3 -m venv .venv
    source .venv/bin/activate
    ```

3.  **Установите зависимости:**
    ```bash
    pip install -r requirements.txt
    ```

4.  **Выполните ноутбуки** последовательно, начиная с `01_EDA_and_Preprocessing.ipynb`, а затем `02_Modeling_and_Interpretation.ipynb`.

## Результаты

После обучения и оптимизации всех моделей была составлена итоговая таблица для сравнения их производительности на тестовой выборке. **Оптимизированный XGBoost** показал наилучшие результаты по ключевой для бизнес-задачи метрике `Recall`.

| Модель                  | Recall (Churn=1) | F1-score (Churn=1) | ROC-AUC |
| :---------------------- | :--------------- | :----------------- | :------ |
| **Optimized XGBoost**   | **0.69**         | **0.61**           | **0.7381**  |
| Optimized LightGBM      | 0.67             | 0.59               | 0.7251  |
| Optimized Random Forest | 0.64             | 0.59               | 0.7241  |
| Optimized Stacking      | 0.62             | 0.59               | 0.7211  |


## Ключевые выводы и интерпретация

Анализ лучшей модели (Optimized XGBoost) с помощью SHAP позволил сформировать портреты клиентов из "группы риска" и "лояльных" клиентов.

#### Портрет клиента из "группы высокого риска":
- Является **новым клиентом** (низкий `tenure`).
- Использует **помесячный контракт**.
- Подключен к **оптоволоконному интернету**.
- Имеет **высокий ежемесячный счет**.
- Оплачивает услуги **электронным чеком**.
- **Не пользуется** дополнительными "защитными" услугами, такими как техподдержка или онлайн-безопасность.

#### Портрет "лояльного" клиента:
- Является **давним клиентом** (высокий `tenure`).
- Имеет **долгосрочный контракт** (на 1 или 2 года).
- Использует **автоматические методы оплаты** (списание с карты/счета).
- У него подключены **дополнительные услуги** (техподдержка, онлайн-безопасность и др.).
